# AIN · карта v15

Окрема нова версія; попередні карти репозиторію не змінені.

## Файли
- `map-ain-v15.tmj` — карта Tiled / WorkAdventure, 160 × 96 клітин по 32 px.
- `ain_conference_v15.png` — графіка, підготовлена для тайлового шару.
- `invisible_collision.png`, `invisible_start.png` — службові тайли з попередньої карти.
- `walk-test-v15.html` — автономний перегляд і тест пересування, відкривається браузером без сервера.
- `collision-preview-v15.png` — червоним позначені непрохідні ділянки.
- `geometry-v15.json` — редагована геометрія та контрольні точки.
- `tools/build_v15.py`, `tools/make_preview_v15.py` — код складання (Python 3 + Pillow).

## Публікація
1. Додати файли до кореня `tarasfedirkko896-code/ain-conference-2026`, зберігши старі версії.
2. Дочекатися успішного розгортання GitHub Pages.
3. Очікувана адреса карти ПІСЛЯ публікації:
   `https://tarasfedirkko896-code.github.io/ain-conference-2026/map-ain-v15.tmj`
4. Вказати цю адресу як Map URL у потрібній кімнаті WorkAdventure.
5. Перевірити живим аватаром вхід, усі стенди, кутові зони й сцену.

Нова адреса не є підтвердженням публікації. Репозиторій і кімната автоматично цим архівом не оновлюються.

## Межі перевірки
Перевірка маршрутизації підтверджує зв'язність контрольних точок на сітці карти. Вона не заміняє тест фізики аватара у WorkAdventure. Меблі й стіни апроксимовані невидимими тайлами. Потрібна остаточна перевірка видимих країв у грі.

Цей пакет містить графіку, стартові позиції та колізії. Відеосцена, трансляція, приватні переговорні, посилання партнерів, доступи й ліміти тарифу налаштовуються окремо у WorkAdventure. Навантаження 200 одночасних користувачів не тестувалося.

## Перебудова
`python tools/build_v15.py path/to/artwork.png`

`python tools/make_preview_v15.py`

Оригінал наданого логотипа збережений у `rozetka-original.png`.
