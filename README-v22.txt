AIN v22 — підписи та схема прохідності

Завантажте map-ain-v22.tmj і всі PNG з папки upload/ в корінь ain_conference_22.
Дочекайтеся успішного GitHub Pages deploy. Map URL:
https://tarasfedirkko896-code.github.io/ain_conference_22/map-ain-v22.tmj

Інші таблички залишені на стінах. Два написи Головна сцена вирівняні по одній висоті, без рамок, нанесені на наявні бортики. Обведені жовтим бортики відкриті за вказівкою користувача. Написи Центральна площа та Вхід прибрані. Логотипи незмінні.
Зала і передній край сцени випрямлені для прямокутної зони слухачів. Точні межі наведено в audience-zone-v22.json та на схемі AIN_v22_audience_zone.jpg. Зону звуку потрібно налаштувати у WorkAdventure; саме зображення її не вмикає.
Зовнішня межа замкнена; усі прохідні клітини доступні зі старту.
Це не підтверджує відповідність кожної внутрішньої стіни малюнку: для цього додано діагностичну схему та тест пересування.
AIN_v22_blocked_zones.jpg показує всі непрохідні клітини червоним.
walk-test-v22.html відкривається без сервера. WASD/стрілки — рух; клік — маршрут; кнопка — межі руху.
Тест у WorkAdventure та навантажувальний тест на 200 людей не виконано.
